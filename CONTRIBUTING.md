# Contribuições · Contributing · Beiträge

[⬅ README](README.md)

### 🇧🇷 Português
Contribuições são bem-vindas (🔓) por pull request, sujeitas a revisão.

1. Abra uma issue descrevendo o problema ou a ideia antes de mudanças grandes.
2. `pip install -e ".[dev]"` e `python -m pytest -q` precisam passar.
3. Mudanças no fluxo de resposta devem vir com o resultado de `eval` antes e depois (`evals/results/latest.md`).
4. Novas perguntas de avaliação vão em `evals/questions.yaml`, com `expected_sources` e `expected_keywords`.
5. Use apenas tags existentes no [SEARCH_CONTENT](https://github.com/repository-for-the-curious/knowledge-hub/blob/main/SEARCH_CONTENT.md); proponha tags novas antes de usá-las.

### 🇺🇸 English
Contributions are welcome (🔓) through pull requests, subject to review.

1. Open an issue describing the problem or idea before large changes.
2. `pip install -e ".[dev]"` and `python -m pytest -q` must pass.
3. Changes to the answer flow must include `eval` results before and after (`evals/results/latest.md`).
4. New eval questions go in `evals/questions.yaml`, with `expected_sources` and `expected_keywords`.
5. Use only tags that exist in [SEARCH_CONTENT](https://github.com/repository-for-the-curious/knowledge-hub/blob/main/SEARCH_CONTENT.md); propose new tags before using them.

### 🇩🇪 Deutsch
Beiträge sind willkommen (🔓) per Pull Request, vorbehaltlich Review.

1. Vor größeren Änderungen ein Issue mit Problem oder Idee eröffnen.
2. `pip install -e ".[dev]"` und `python -m pytest -q` müssen erfolgreich sein.
3. Änderungen am Antwortablauf brauchen `eval`-Ergebnisse vorher und nachher (`evals/results/latest.md`).
4. Neue Evaluationsfragen gehören in `evals/questions.yaml`, mit `expected_sources` und `expected_keywords`.
5. Nur Tags aus dem [SEARCH_CONTENT](https://github.com/repository-for-the-curious/knowledge-hub/blob/main/SEARCH_CONTENT.md) verwenden; neue Tags vorher vorschlagen.
